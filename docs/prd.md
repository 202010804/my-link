# 🔗 마이링크 (MyLink) - 제품 요구사항 정의서 (PRD)

본 문서는 링크트리(Linktree) 클론 서비스인 **'마이링크(MyLink)'** 프로젝트의 제품 요구사항 정의서(Product Requirement Document)입니다. 개인이 보유한 다채로운 디지털 채널을 단 하나의 스마트한 링크로 연결하는 최적의 사용자 경험 설계를 목적으로 작성되었습니다.

---

## 1. 프로젝트 개요 (Project Overview)

### 1.1 프로젝트명
- **마이링크 (MyLink)**

### 1.2 서비스 목적
- 인스타그램, 틱톡 등 대다수 주요 SNS 플랫폼이 프로필 내 **'단 하나의 링크'**만 허용하는 제약을 극복합니다.
- 사용자가 운영하는 다중 채널(블로그, GitHub, 포트폴리오, 이메일, 쇼핑몰 등)을 모바일 화면에 최적화된 하나의 마이크로 랜딩 페이지로 통합 및 허브화합니다.

### 1.3 대상 사용자 (Target Audience)
1. **멀티채널 크리에이터 및 인플루언서:** 유튜브, 인스타그램, 블로그 등 다양한 채널을 동시에 운영하는 사용자.
2. **취업 준비생 및 프리랜서/대학생:** 본인의 노션 포트폴리오, GitHub 링크, 연락처 등을 세련되게 모아 공유하고자 하는 사용자.
3. **1인 창업가 및 소상공인:** 스마트스토어, 공식 웹사이트, 실시간 고객 상담 채널(카카오톡 채널 등)을 모아 보여주고자 하는 비즈니스 운영자.

## 2. 제품 로드맵 및 기능 분류 (Feature Categorization)

개발 및 출시 주기를 신속하고 안정적으로 유지하기 위해 기능을 **필수 요구사항(Must-Have)**과 **선택 요구사항(Nice-to-Have)**으로 명확하게 나눕니다.

### 2.1 필수 기능 (Must-Have)
- **사용자 인증 및 계정 관리:** 회원가입, 로그인 및 개인화 주소 확보.
- **마이링크 커스텀 주소 제공:** `mylink.app/[username]` 고유 식별 링크 지원.
- **프로필 관리:** 대표 이름, 프로필 이미지, 다중 줄 소개 문구 수정 기능.
- **링크 관리 (핵심 기능):** 링크 추가, 수정, 삭제, 노출 상태 토글 및 드래그 앤 드롭을 통한 노출 순서 편집.
- **모던 테마 설정:** 미리 제공되는 세련된 프리셋 테마(네오브루탈리즘, 미니멀, 다크/라이트, 그라데이션) 선택.
- **모바일 최적화 뷰어:** 방문자가 접속하여 링크를 클릭할 수 있는 초고속 로딩 모바일 반응형 페이지.

### 2.2 선택 기능 (Nice-to-Have)
- **통계 및 분석 대시보드:** 누적 방문자 수, 링크별 일일 클릭 수 및 클릭률(CTR) 통계 대시보드 제공.
- **소셜 미디어 아이콘 연결:** 링크 카드 형태가 아닌, 프로필 하단 또는 상단에 아이콘 형태의 소셜 링크 바 배치.
- **링크 꾸미기 및 에니메이션:** 핵심 링크에 주의를 끄는 애니메이션 효과(바운스, 플래시 등) 추가.
- **고급 테마 커스터마이징:** 배경 이미지 업로드 및 사용자 지정 HSL 그라데이션 커스텀.
- **임시 비공개 및 비밀번호 보안 링크:** 특정 링크에 비밀번호를 설정하거나, 특정 기간에만 한시 노출하는 기능.

## 3. 기능별 요구사항 명세 (Detailed Requirements)

---

### 3.1 [필수] 사용자 인증 및 계정 관리 (Authentication)

#### 3.1.1 기능 상세 설명
- 사용자가 서비스를 이용하고 본인만의 마이링크 주소를 소유하기 위해 가입하고 인증하는 체계입니다.

#### 3.1.2 세부 요구사항
- **가입 수단:** 이메일 및 비밀번호 가입 방식을 필수로 지원하며, 향후 편리한 가입을 위해 소셜 로그인(Google, Kakao) 확장을 고려한 스키마를 설계합니다.
- **중복 검사:** 가입 시 사용자가 원하는 고유 주소명(Username)의 실시간 중복 검사를 실행합니다.
  - 예: `mylink.app/jimin` 생성 시 `jimin`이 기존 가입자와 중복되는지 검증.
- **보안 규칙:** 비밀번호는 최소 8자 이상, 영문/숫자/특수문자 조합 조합 규칙을 적용하고 단방향 해시 암호화(bcrypt 등)를 통해 저장합니다.

---

### 3.2 [필수] 프로필 커스터마이징 (Profile Customization)

#### 3.2.1 기능 상세 설명
- 방문자가 링크 페이지에 접속했을 때 가장 먼저 마주하는 최상단 프로필 카드 영역을 설정합니다.

#### 3.2.2 세부 요구사항
- **프로필 이미지:** 
  - PNG, JPG, GIF 형식을 지원하며 최대 5MB 용량 제한을 둡니다.
  - 업로드된 이미지는 서버 또는 클라우드 스토리지에 저장 후 원형(Circle) 형태로 크롭하여 렌더링합니다.
  - 프로필 이미지가 없는 경우, 기본 아바타 캐릭터 또는 이니셜 텍스트 플레이스홀더를 표시합니다.
- **텍스트 정보:**
  - **프로필 타이틀(이름):** 최대 30자 제한.
  - **바이오(소개글):** 한 줄 소개글 형태로 최대 100자까지 줄바꿈을 지원합니다.

---

### 3.3 [필수] 링크 관리 시스템 (Link Management)

#### 3.3.1 기능 상세 설명
- 사용자가 자신의 다중 채널 링크 카드를 마음대로 구성하고 정렬하는 핵심 제어판 기능입니다.

#### 3.3.2 세부 요구사항
- **링크 추가/편집:**
  - 각 링크 카드는 **'제목(Title)'**과 **'목적지 URL(Destination URL)'** 정보를 가집니다.
  - 입력된 URL은 올바른 형식(HTTP/HTTPS)인지 유효성 검사(RegEx)를 거칩니다.
- **노출 제어:**
  - 카드 우측의 활성화 토글 스위치(Toggle Switch)를 활용해 방문자 화면 노출 여부를 실시간으로 켜고 끌 수 있습니다.
- **순서 재정렬 (Drag & Drop):**
  - 카드 왼쪽의 핸들 아이콘을 드래그하여 직관적으로 노출 순서를 바꿀 수 있습니다. 순서 변경은 데이터베이스에 즉시 정수형 순서값(`order_index`)으로 업데이트됩니다.

---

### 3.4 [필수] 모던 테마 선택 및 뷰어 (Themes & Responsive Viewer)

#### 3.4.1 기능 상세 설명
- 페이지를 트렌디하고 아름답게 꾸미고, 최종 소비자가 접속했을 때 지연 시간 없이 페이지를 보여주는 뷰어 페이지입니다.

#### 3.4.2 세부 요구사항
- **프리셋 테마 제공:** 
  - 최소 4가지 스타일의 모던 테마 프리셋을 제공합니다.
    1. **미니멀 화이트 (Minimal White):** 정갈한 회색 조 바탕에 깔끔한 테두리 카드.
    2. **네오브루탈리즘 (Neobrutalism):** 굵은 테두리와 쨍한 파스텔 배경, 단단한 검은색 3D 그림자.
    3. **다크 모드 (Sleek Dark):** 세련된 차콜 블랙 톤의 야간 최적화 테마.
    4. **오로라 그라데이션 (Aurora Gradient):** 몽환적인 파스텔 네온 그라데이션 배경.
- **초고속 방문자 뷰어:**
  - 방문자가 `mylink.app/username`으로 접속 시 모바일에 완전 최적화된 반응형 UI로 즉각 렌더링됩니다.
  - 성능 및 SEO 최적화를 위해 Next.js의 SSR(Server-Side Rendering) 혹은 ISR(Incremental Static Regeneration) 방식을 접목하여 첫 로딩 속도를 극대화합니다.

---

### 3.5 [선택] 방문 통계 분석 (Analytics Dashboard)

#### 3.5.1 기능 상세 설명
- 사용자가 자신의 다중 링크 페이지가 얼마나 활발히 공유되고 마케팅 효과를 내는지 계량 분석하는 도구입니다.

#### 3.5.2 세부 요구사항
- **수집 데이터:**
  - **방문 수 (Page Views):** 랜딩 페이지 전체 로드 횟수.
  - **링크 클릭 수 (Link Clicks):** 개별 링크 카드가 클릭된 횟수.
  - **클릭률 (CTR):** `(전체 클릭수 / 전체 방문수) * 100` 수치 자동 계산.
- **필터링:** 최근 7일, 최근 30일 간의 기간 설정 기능을 지원합니다.
- **보안 및 프라이버시:** 무분별한 리소스 차단 및 개인정보 침해 예방을 위해 IP 기반의 24시간 중복 조회 차단 필터를 구축합니다.

## 4. 논-기능 요구사항 (Non-Functional Requirements)

- **응답 속도 (Performance):** 방문자 링크 뷰어 페이지는 모바일 네트워크 환경(LTE 등)에서도 첫 로딩(FCP: First Contentful Paint)이 1.5초 이내에 완료되어야 합니다.
- **모바일 우선 설계 (Mobile-First):** 대다수 인바운드 트래픽이 인스타그램 등 인앱 브라우저를 통해 유입되므로, 모바일 웹 해상도(320px ~ 480px)에서 깨짐이 없고 완벽한 터치 인터랙션을 보장해야 합니다.
- **안정성 (Reliability):** 사용자의 관리자 페이지 저장 동작 및 정렬 조작은 비동기 API 통신 실패 시 사용자에게 경고 및 복구 UI를 명확히 제시해야 합니다.

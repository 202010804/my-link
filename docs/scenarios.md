# 👥 마이링크 (MyLink) - 사용자 시나리오 (User Scenarios)

본 문서는 **'마이링크(MyLink)'** 서비스의 핵심 사용자층(방문자와 소유자)이 겪는 실제 사용 시나리오를 구성한 문서입니다. 각 시나리오는 제품 요구사항 정의서(PRD)의 세부 기능과 직관적으로 연결될 수 있도록 기획되었습니다.

---

## 1. 방문자 시나리오 (Visitor Scenarios)

방문자는 크리에이터나 소상공인의 단일 프로필 링크를 클릭해 유입되는 최종 소비자입니다.

### 1.1 마이링크 페이지 방문 및 프로필 식별 과정
- **시나리오 1:** 사용자는 **소유자가 운영하는 다양한 디지털 채널들을 한눈에 파악하기 위해** 소유자의 인스타그램 프로필에 기재된 `mylink.app/[username]` 고유 주소를 클릭하여 마이링크 페이지로 진입한다.
- **시나리오 2:** 사용자는 **접속한 마이링크 페이지가 자신이 찾던 크리에이터가 맞는지 식별하기 위해** 페이지 최상단에 자동으로 생성된 둥근 형태의 이니셜 텍스트 배지와 대표 타이틀(이름)을 확인한다.
- **시나리오 3:** 사용자는 **해당 크리에이터가 제공하는 가치나 채널의 성격을 파악하기 위해** 프로필 이니셜 배지 하단에 정렬된 다중 줄 바이오(소개글) 문구를 정독한다.

### 1.2 링크 탐색 및 외부 채널 이동 과정
- **시나리오 4:** 사용자는 **크리에이터의 최신 동향이나 상세 포트폴리오를 확인하기 위해** 목록에 직관적인 카드 형태로 나열된 개별 링크의 제목을 탐색한다.
- **시나리오 5:** 사용자는 **실제 소셜 채널이나 외부 웹사이트로 안전하게 이동하기 위해** 나열된 링크 카드 중 원하는 항목을 탭(클릭)하여 새 창으로 목적지 URL에 접속한다.
- **시나리오 6:** 사용자는 **모바일 인앱 브라우저나 다양한 디바이스 환경에서 흐트러짐 없이 원활하게 콘텐츠를 탐색하기 위해** 최적화된 반응형 모바일에 최적화된 테마 뷰어를 스크롤한다.

## 2. 소유자 시나리오 (Owner Scenarios)

소유자는 자신의 마이링크 계정을 개설하여 다중 링크와 프로필 브랜딩을 제어하는 주체입니다.

### 2.1 계정 가입 및 프로필 구성 과정
- **시나리오 1:** 사용자는 **자신만의 고유 주소가 탑재된 마이링크 페이지를 개설하기 위해** 사용되지 않은 Username(고유 주소명)을 실시간으로 조회하여 회원가입을 완료한다.
- **시나리오 2:** 사용자는 **대표 이미지를 업로드하는 번거로움 없이 정갈하게 프로필을 꾸미기 위해** 대표 이름의 첫 문자가 파싱되어 자동 생성된 이니셜 텍스트 배지를 확인하고 소개 문구를 입력한다.

### 2.2 링크 추가 과정 (Link Creation)
- **시나리오 3:** 사용자는 **새로 발행한 소셜 채널이나 외부 홍보 페이지를 방문자에게 노출하기 위해** 관리자 대시보드에서 `새 링크 추가` 버튼을 클릭한다.
- **시나리오 4:** 사용자는 **추가한 링크 카드가 실제 작동하고 의미 있는 정보를 담게 하기 위해** 직관적인 제목(Title)과 검증된 목적지 URL(Destination URL)을 입력하여 저장한다.
- **시나리오 5:** 사용자는 **일시적으로 특정 링크를 숨기거나 다시 복구하기 위해** 개별 링크 카드의 실시간 노출 스위치 토글을 끄거나 켠다.

### 2.3 링크 수정 및 편집 과정 (Link Modification)
- **시나리오 6:** 사용자는 **잘못 기재된 주소나 계정 정보를 갱신하기 위해** 수정하고자 하는 링크 카드를 클릭하여 텍스트 및 URL 값을 변경한다.
- **시나리오 7:** 사용자는 **가장 중요한 핵심 이벤트 링크를 최상단에 강조 배치하기 위해** 링크 카드의 드래그 핸들을 활용해 위아래로 끌어다 놓으며 노출 순서를 정렬한다.
- **시나리오 8:** 사용자는 **자신이 제공하는 콘텐츠의 성격에 부합하는 세련된 아우라를 연출하기 위해** 시스템이 프리셋으로 제공하는 4가지 모던 테마(미니멀, 네오브루탈리즘, 다크, 그라데이션) 중 하나를 선택해 즉시 적용한다.

### 2.4 링크 삭제 과정 (Link Deletion)
- **시나리오 9:** 사용자는 **더 이상 운영하지 않거나 홍보 목적이 다한 오래된 채널 링크를 배제하기 위해** 해당 링크 카드의 휴지통 아이콘을 클릭하여 관리 목록에서 완전히 삭제한다.

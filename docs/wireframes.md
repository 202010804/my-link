# 📐 마이링크 (MyLink) - 와이어프레임 설계서 (Wireframe Designs)

본 문서는 **'마이링크(MyLink)'** 서비스의 핵심 화면인 **방문자용 모바일 뷰어(Visitor Mobile Viewer)**와 **소유자용 관리자 대시보드(Owner Admin Dashboard)**의 시각적 레이아웃 및 UX 구성 요소를 정의합니다. 

본 설계서는 아스키 아트(ASCII Art) 레이아웃 모형과 컴포넌트 사양 기술 방식을 결합하여, 향후 프론트엔드 퍼블리싱 시 직관적인 도면 역할을 하도록 구성되었습니다.

---

## 1. 방문자용 모바일 최적화 뷰어 (Visitor Mobile Viewer)

방문자가 SNS 링크 등을 타고 인앱 브라우저로 진입했을 때 보게 되는 모바일 화면의 기본 구도입니다.

### 1.1 모바일 뷰어 아스키 와이어프레임

```text
+--------------------------------------------+
|                                            |
|                [ JIMIN.AI ]                | <--- 상단 헤더 / 로고 영역
|                                            |
|                +----------+                |
|                |    JM    |                | <--- 이니셜 프로필 배지 (자동 생성)
|                +----------+                |
|                  이지민                    | <--- 프로필 타이틀 (이름)
|       AI & 소프트웨어공학 전공 대학생      | <--- 바이오 (소개글)
|                                            |
|                                            |
|  +--------------------------------------+  |
|  | 🧠 MRI 의료 이미지 판독 분류기        |  | <--- 링크 카드 1 (핵심 프로젝트)
|  |    PyTorch / 99.2% Acc.              |  |
|  +--------------------------------------+  |
|                                            |
|  +--------------------------------------+  |
|  | ⚡ 스마트 에너지 그리드 수요 예측기    |  | <--- 링크 카드 2
|  |    Next.js + FastAPI                 |  |
|  +--------------------------------------+  |
|                                            |
|  +--------------------------------------+  |
|  | 🤖 학사 행정 지원 RAG 에이전트        |  | <--- 링크 카드 3
|  +--------------------------------------+  |
|                                            |
|                                            |
|                +----------+                |
|                | INSTA/GH |                | <--- 소셜 미디어 아이콘 바 (선택)
|                +----------+                |
|                                            |
|       © 2026 Jimin Lee. Powered by MyLink  | <--- 최하단 푸터
+--------------------------------------------+
```

### 1.2 주요 컴포넌트 세부 명세

1. **상단 브랜드 헤더 (Brand Header):**
   - 서비스 브랜드명(`MyLink`) 또는 커스텀 로고가 가운데 정렬로 노출됩니다.
2. **자동 생성 이니셜 프로필 배지 (Initials Avatar Badge):**
   - 가로/세로 `80px` 크기의 원형 또는 둥근 모서리 사각형 영역입니다.
   - 업로드 기능이 없으므로, 이름의 이니셜 `JL`(Jimin Lee)이 정중앙에 고대비 폰트로 자동 매핑됩니다.
3. **텍스트 프로필 메타 (Text Metadata):**
   - **이름:** 18px Bold 폰트, 자간 타이트하게 조정.
   - **소개문구:** 14px Regular 폰트, 최대 3줄 노출 및 자동 줄바꿈.
4. **링크 카드 목록 (Link Cards List):**
   - 세로 폭 `60px ~ 80px` 내외의 버튼형 컨테이너입니다.
   - Neobrutalism 테마 적용 시: 배경색 칠하기 + `border-3 border-black` + 우하단 단단한 검은색 그림자(`shadow-[4px_4px_0px_#000]`)를 결합합니다.
   - 카드를 터치/클릭하면 목적지 URL이 새 탭(`_blank`)으로 열립니다.

## 2. 소유자용 관리자 대시보드 (Owner Admin Dashboard)

소유자가 회원가입 후 진입하여 본인의 프로필 정보 및 다중 링크 목록을 관리하는 데스크톱 전용 웹 제어판 레이아웃입니다. 화면의 공간을 낭비하지 않기 위해 **2열 분할 구성(Split View)**을 채택합니다.

### 2.1 대시보드 아스키 와이어프레임

```text
+--------------------------------------------------------------------------------------------------+
|  [MYLINK.APP]  / Dashboard                     [ jimin.lee.ai@example.com ]  [ 로그아웃 ]        |
+--------------------------------------------------------------------------------------------------+
|                                                                 |                                |
|  [1열: 좌측 - 프로필 및 링크 콘텐츠 제어 영역]                    | [2열: 우측 - 실시간 모바일 프리뷰] |
|                                                                 |                                |
|  +-----------------------------------------------------------+  |  +--------------------------+  |
|  | 👤 프로필 설정 (Profile Info)                             |  |  |      [ LIVE PREVIEW ]      |  |
|  |   이름  [ 이지민                   ]                      |  |  |                            |  |
|  |   소개  [ AI & 소프트웨어 전공 대학생                     ] |  |  |        +----------+        |  |
|  |                                    [ 프로필 변경 저장 ]   |  |  |        |    JL    |        |  |
|  +-----------------------------------------------------------+  |  |        +----------+        |  |
|                                                                 |  |          이지민            |  |
|  +-----------------------------------------------------------+  |  |                            |  |
|  | 🔗 링크 관리판 (Manage Links)                             |  |  |  +----------------------+  |  |
|  |   +-----------------------------------------------------+ |  |  |  | 🧠 MRI 분류기        |  |  |
|  |   | [추가] + 새 링크 카드 만들기                         | |  |  |  +----------------------+  |  |
|  |   +-----------------------------------------------------+ |  |  |  | ⚡ 에너지 예측기     |  |  |
|  |                                                         | |  |  |  +----------------------+  |  |
|  |   +-----------------------------------------------------+ |  |  |                            |  |
|  |   | [::] 🧠 MRI 의료 이미지 판독 분류기        [x] 활성화 | |  |  |                            |  |
|  |   |      URL: https://github.com/...            [삭제]  | |  |  |                            |  |
|  |   +-----------------------------------------------------+ |  |  |                            |  |

|  +-----------------------------------------------------------+  |                                |
|                                                                 |                                |
```

### 2.2 대시보드 컴포넌트 세부 명세

1. **프로필 설정 폼 (Profile Config Form):**
   - 텍스트 입력 칸(`Input`)으로 구성되어 있으며, 입력 즉시 우측의 실시간 모바일 프리뷰에 텍스트 데이터가 반영됩니다.
   - 업로더 파일 입력 컴포넌트는 요구사항 반영에 따라 존재하지 않습니다.
2. **새 링크 생성 버튼 (Add New Link Button):**
   - 제어판 상단에 굵게 강조 표시된 버튼입니다. 클릭 시 리스트 맨 위에 제목 및 URL 공란 상태의 빈 카드가 즉각 삽입됩니다.
3. **개별 링크 카드 아이템 (Link Item Container):**
   - **드래그 핸들 `[::]`:** 카드 좌측에 위치하여, 마우스를 클릭해 위아래로 끌어당기면 타 카드와 스왑(Swap) 정렬됩니다.
   - **텍스트 입력 필드:** 제목과 URL을 바로 편집할 수 있도록 인라인 편집 인풋을 구성합니다.
   - **노출 토글 스위치 `[x] 활성화`:** 토글을 끄면 카드 스타일이 반투명 블러 상태로 흐려지며, 우측 프리뷰 패널에서도 즉시 사라집니다.
   - **삭제 버튼 `[삭제]`:** 클릭 시 유저에게 확인 대화상자(Modal)를 띄운 후 영구 삭제합니다.
4. **실시간 모바일 프리뷰 영역 (Live Preview Device Frame):**
   - 화면 우측에 세로 형태로 배치된 스마트폰 목업(Mockup) 프레임 레이아웃입니다.
   - 소유자가 좌측 제어판에서 글자를 지우거나 드래그하여 순서를 바꿀 때마다 `React State`가 갱신되어 새로고침 없이 즉각적인 애니메이션 피드백을 선사합니다.

## 3. UI 테마 프리셋 와이어프레임 사양 (Preset Styles Specification)

소유자는 좌측 관리창 하단에서 다음과 같이 4개의 프리셋 테마 중 하나를 선택할 수 있으며, 이 스타일 값은 즉시 전체 뷰어 페이지에 배포됩니다.

- **Minimal White 테마:**
  - 배경색: `#FFFFFF` / 주 텍스트색: `#111111`
  - 카드 테두리: `border border-zinc-200 shadow-sm`
- **Neobrutalism 테마:**
  - 배경색: `#FAF7F0` (따뜻한 미색) / 주 텍스트색: `#000000`
  - 카드 테두리: `border-3 border-black shadow-[4px_4px_0px_#000]`
- **Sleek Dark 테마:**
  - 배경색: `#09090B` (차콜 블랙) / 주 텍스트색: `#F4F4F5`
  - 카드 테두리: `border border-zinc-800 bg-zinc-900/50`
- **Aurora Gradient 테마:**
  - 배경색: `bg-gradient-to-br from-indigo-500 via-purple-500 to-pink-500` (네온 파스텔)
  - 카드 테두리: `border border-white/20 bg-white/10 backdrop-blur-md text-white`
